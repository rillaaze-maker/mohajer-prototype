Typography — Radical

One family covers Persian, Latin, and Persian digits, so FA and EN never diverge typographically. Six weights are loaded: 300 / 400 / 500 / 600 / 700 / 800.

Digits. Toman uses Persian numerals (۱۰۰,۰۰۰,۰۰۰). Dollars always use Latin numerals ($682.00) in both languages — $۶۸۲.۰۰ reads as broken. Every number carries tabular-nums so animated values do not jitter.

The one colour rule: gold only ever touches black. On the dark card it reads as money. On the light canvas the same hue reads dated. Light surfaces get ink, grey and white — nothing else. Green marks defensible, never success in general.

Logo — production sizes

Design the master as vector on a 24×24 grid. If it survives at 24px it survives everywhere; if it only works large, it is not an app mark.
